# Kala Angan — kalaangan.lifestyle

> **Beauty in Every Detail**

A modern portfolio & catalog website for Kala Angan — a lifestyle brand offering Home Decor, Fashion Jewellery, Festive Decorations, Gifting & Art.

## Tech Stack

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS v4**
- **Lucide React** (Icons)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

Deploy to [Vercel](https://vercel.com) for free:

```bash
npx vercel
```

Then connect your domain `kalaangan.lifestyle` in the Vercel dashboard.

## Adding Products

Edit `src/data/products.json` to add or update products. Each product has:

```json
{
  "id": 1,
  "name": "Product Name",
  "slug": "product-name",
  "category": "home-decor",
  "price": 499,
  "description": "...",
  "images": ["/images/products/product-name.jpg"]
}
```
